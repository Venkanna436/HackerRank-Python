# HackerRank-Python

This repository contains Python practice solutions organized by HackerRank 30 Days of Code days.

## Structure

```text
HackerRank-Python/
│
├── Python/
│   ├── Day_01/
│   ├── Day_02/
│   ├── Day_03/
│   └── ...
│
└── README.md
```

## Purpose

- Store daily Python challenge solutions
- Keep each day in a separate folder
- Maintain a simple, clean project layout for practice and revision

## Notes

The repository now includes a starter scaffold from Day_01 through Day_30, with each day in its own folder and a `solution.py` file ready for coding.
